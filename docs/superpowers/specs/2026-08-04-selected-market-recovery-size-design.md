# 选中市场补单数量设计

## 目标

当市场存在可管理的未配对库存时，补单必须只降低净敞口，互补买单数量严格等于当前未配对份额；不得叠加普通做市数量。

## 方案

1. 保持现有的配对成本上限、最小下单量和互补 token 判定。
2. 对已选市场的未配对库存，返回唯一的互补报价，数量为 `abs(unpaired)`。
3. 裸仓期间不保留该市场的普通 YES/NO 做市单；库存配平后恢复原有的双边普通报价。

## 拒绝的方案

- 继续采用 `普通报价 + 补单缺口`：会使 68 YES 生成 137 NO，补单完成后反向扩大库存。
- 只把总订单量截断为普通报价大小：无法保证清除净敞口。

## 验收

- 已选市场有 68 YES、无 NO 时，只生成一笔 `BUY NO 68`。
- 已选市场有 68 NO、无 YES 时，只生成一笔 `BUY YES 68`。
- 已配平或净敞口小于 `MIN_TAKER_SHARES` 时，保持现有普通报价行为。
- 现有成本上限和最小订单量保护不变。
