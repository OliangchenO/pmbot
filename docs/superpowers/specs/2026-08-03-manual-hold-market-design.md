# 单市场完全人工持仓

## 目标

对 `risk.manual_hold_cids` 中的市场，bot 完全停止处理：不将其选入、
不生成普通报价、不执行库存恢复、不会提交 FAK 强制对冲，也不写入该市场
的报价/恢复指标。既有仓位保留，交由人工处理或等待结算。

## 配置

在 `risk` 下新增 `manual_hold_cids`，默认空列表。当前指定的市场为：

```yaml
risk:
  manual_hold_cids:
    - 0xa1a4a8b493cd978b359c3deab56955d80a4b0b14c806beea6bd37b4b3a3e4415
```

## 运行时行为

`Bot._quote_all` 在构建全部受管市场后、读取订单簿和计算仓位之前过滤这些
CID。这样已持仓市场不会走普通报价、被动补仓、升级补仓或 FAK 强制对冲。
扫描选择同时排除这些 CID，避免市场重新进入 `self.markets`。

该开关不会撤销交易所上已经存在的订单：撤单是独立的实时操作，须得到明确
授权并在交易所侧回读确认。变更仅在 bot 重新加载新代码和配置后生效；不会
修改已运行进程的内存状态。

## 验证

新增测试覆盖：手工持仓 CID 即使被选中或由 `held_markets()` 返回，也不会
进入报价更新或触发库存恢复；其他市场维持原有处理。配置加载后使用该 CID
运行该测试，并执行相关 `tests/test_main.py`。
