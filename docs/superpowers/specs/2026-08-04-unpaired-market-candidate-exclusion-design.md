# 未配平市场候选排除设计

## 目标

存在未配平敞口的市场继续由库存管理路径补单，但不参与普通奖励市场的扫描候选、排名和 top-N/sticky 选择。

## 规则

1. 在重扫时，收集所有 `abs(unpaired_shares) >= MIN_TAKER_SHARES` 的已持仓市场 CID。
2. 将这些 CID 从普通候选和最终 `self.markets` 选择中排除，释放名额给平仓候选市场。
3. 已排除市场仍由 `broker.held_markets()` 纳入 `_quote_all()` 和库存管理，仅允许互补补单。
4. 已排除市场离开 `self.markets` 时，不取消其补单订单或行情订阅。
5. 敞口配平后，该 CID 不再被排除，并在下一次扫描重新参与候选排序。

## 边界

- 不等同于 `manual_hold_cids`：本规则不停止补单、强制对冲判定、合并、退出或持仓行情订阅。
- 不改变普通平仓市场的 sticky 与 top-N 规则。
- 不改变补单数量、补单保队列和配对成本硬上限规则。

## 验收

- 一个已选市场出现未配平库存后，在重扫结果中不再占用 top-N 名额。
- 该市场的互补补单仍保持可管理，且不会因离开 `self.markets` 被撤销。
- 当其未配平库存降至阈值以下，下一次重扫可再次被选中。
