# 空报价市场补位重扫

## 目标

当已选、空仓市场在报价轮次中未生成任何可提交报价时，触发一次受防抖保护的重新扫描，以补足报价槽位。持仓市场继续由库存恢复和退出路径管理，不因本机制被移除。

## 触发条件

- 市场属于当前 `self.markets`（即已选市场）；
- 本轮最终 `desired` 为空；
- 该市场没有未配对库存（`abs(unpaired) < MIN_TAKER_SHARES`）；
- 距离上一次轮换重扫已超过现有 `ROTATE_MIN_INTERVAL_SECS`。

满足条件的市场 condition id 会被汇总；本轮报价处理结束后最多调用一次现有 `_rescan()`。

## 不触发的情况

- 存在未配对库存：保留市场和双 token 行情订阅，继续补仓、退出与强平保护链路；
- 只有单边报价仍可提交：不视为无报价；
- 在防抖窗口内：不重复扫描。

## 实现边界

复用现有 `_rescan()`、轮换防抖时间戳和候选市场筛选规则；不改变报价定价、仓位限制、风险阈值、订单提交或 `config.yaml`。

## 测试

1. 已选空仓市场的最终报价为空时触发一次重扫。
2. 已选且有未配对库存的市场最终报价为空时不触发重扫。
3. 多个空报价市场、或同一防抖窗口内多轮报价，最多重扫一次。
