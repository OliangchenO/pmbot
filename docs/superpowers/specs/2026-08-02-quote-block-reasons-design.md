# 未报价原因与中文运行日志设计

## 目标

让运行面板逐市场说明没有有效报价的首要原因，并将 pmbot 自身的运行日志改为易读中文；审计 JSON 的事件名和字段保持不变。

## 设计

`Bot` 在每轮报价计算时记录每个已管理市场的 `QuoteBlockReason`。该状态只用于当前运行面板：报价齐全时为空；未报价时按执行顺序保留第一个阻断条件。面板增加“未报价原因”列，显示中文说明；单边保护包含侧别和剩余时间。

阻断原因的优先级与真实报价链路一致：临近结算、行情过期、订单簿不可报价、主题仓位上限、市场冷却、策略无法形成报价、单边流量保护。没有可确认原因时显示“等待本轮报价诊断”。

全部 `pmbot.*` logger 的文本改为中文。结构化标识（例如 `ORDER_PLACED`、`FORCED_HEDGE_DEFERRED`、`reason=`）以及第三方异常文本原样保留，确保审计、日志检索和故障定位兼容。第三方库自身的日志不修改。

## 验收

- Spider-Man 这类未报价行能显示当前单边流量保护及剩余时间。
- 盘口或策略导致的空报价有明确中文说明，不再只显示 `—`。
- 原有审计 JSON 事件格式不变。
- 新增单元测试覆盖未报价原因优先级、到期时间格式和面板渲染。
